# Agent Instructions (`agent.md`)

Welcome to the AI Class workspace. This document provides instructions, guidelines, and context for AI coding assistants working in this repository.

---

## 🎯 Overview & Purpose
- **Context**: AI Class projects, assignments, experiments, and code solutions.
- **Goal**: Collaborate effectively with the user to build, explain, refactor, and test AI/ML models, scripts, web applications, and algorithms.

---

## 🛠️ Technology Stack & Environment
- **Language**: Python 3.x / JavaScript / HTML / CSS (as required by assignments)
- **Frameworks**: PyTorch, TensorFlow, Scikit-Learn, Pandas, NumPy, Next.js / Vite (for Web UI)
- **Environment**: Windows OS / PowerShell

---

## 📋 General Guidelines for AI Agents

### 1. Code Quality & Standards
- Write clean, modular, and readable code with descriptive variable and function names.
- Include concise docstrings and inline comments explaining key logic, math formulas, or algorithms.
- Preserve existing comments and codebase documentation unless explicitly asked to update them.

### 2. Problem Solving & Pair Programming
- Break down complex AI/ML or coding tasks into clear, logical steps.
- Explain concepts clearly when requested, suitable for an educational environment.
- Prefer empirically verified code over assumptions.

### 3. Tool Usage & Execution Safety
- Inspect relevant files before making edits.
- Run unit tests or verification commands whenever code is added or modified.
- Respect file paths, working directories, and system permissions.
